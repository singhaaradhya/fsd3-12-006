1. file -> write File 
Read File, Append File 

2. Folder ->
-  MKdir/md
-  rmdir/rm
-  readdir 

3. File Metadat
-  stat
-  lstat

4. watch-> watch, unwatch

5. stream -> readstream(), writestream
